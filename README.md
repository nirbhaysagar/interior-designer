# Architectural & Interior Design Showcase Suite

A client presentation platform featuring an interactive **top concept switcher bar** that allows clients to seamlessly switch between distinct interior architecture & design concepts from a single URL without juggling multiple links.

## 🏛️ Featured Design Concepts

1. **Vivida (Warm Architectural Minimalist)**
   - Curated natural oak, editorial typography, and structured spatial grids.
   - Interactive **Before / After Spatial Transformation** slider.
   - Tactile materiality catalog and architectural project case studies.

2. **Atelier Noir (Haute Dark Luxury)**
   - Chiaroscuro lighting, monolithic stone, and brushed champagne brass.
   - Interactive **Midnight (2200K) / Gallery (3000K)** ambient lighting mode switcher.
   - Comprehensive materials laboratory and private residence portfolio.

3. **Céleste (Ethereal Pinterest Sanctuary)**
   - Bone limewash, soft cloud curves, and sheer Belgian flax linen.
   - 8-piece Pinterest-style masonry portfolio with client "Save / Like" heart buttons.
   - Soft sunlight mood switcher (*Morning Sun*, *Golden Hour*, *Twilight Calm*).

4. **Sonder House (Modern Nature Villas)**
   - Slate-blue architectural frame and cubic residential architecture in nature.
   - **GSAP-powered entrance animations** and smooth 1-second delayed scroll reveals.
   - Interactive **Available Villa Layouts Modal** (Types A, B, C).

5. **Arkitect\* (3D Spatial Depth Deck)**
   - **Three.js ambient 3D depth canvas** with interactive mouse parallax.
   - Signature **3D perspective tilt & stacking card deck** (*Ocean Wave, Puzzle Tower, Honeycomb, Mirror Horizon*).
   - Interactive **3D Spatial Anatomy Layer Explorer** (*Structural Core, Kinetic Facade, Living Volume*).
   - Global Chronology sortable selected works index.

6. **Spazio Milano (Italian Haute Architecture)**
   - Milanese palazzos, Ceppo di Gré stone, and Italian Noce Canaletto walnut.
   - Interactive **Bilingual Switcher (`EN` / `IT`)**.
   - *Il Metodo Italiano* 4-phase architectural process and *Materia & Sostanza* archive.

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **Three.js** (WebGL 3D ambient spatial background)
- **GSAP** (GreenSock Animation Platform)
- **Tailwind CSS**
- **Lucide React Icons**

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

## 🌐 Live Client Concept Switcher

Navigate to `http://localhost:3000/?concept=<id>` to directly deep-link to any concept:
- `?concept=vivida`
- `?concept=concept-2`
- `?concept=concept-3`
- `?concept=concept-4`
- `?concept=concept-5`
- `?concept=concept-6`
